# 预测基线、策略消融与费用敏感性

这些实验用于回答两个问题：TCN 是否比简单预测更准确，以及最终收益究竟来自哪个策略模块。所有方案共用相同的交易日、初始资金、下一开盘成交、T+1、期末清算和费用假设。

## 一键运行

```bash
python evaluate.py
```

正式期默认读取 `results/signals.csv`，避免重复训练 TCN；Ridge 基线仍从原始行情重新拟合。加 `--recompute` 可同时重训两个原模型。结果写入 `evaluation_output/`：

- `prediction_metrics.csv`：TCN、零收益预测和 Ridge 的方向准确率、收益 MAE/RMSE、点位 MAE/RMSE；
- `ridge_predictions.csv`：Ridge 的逐日预测和训练信息边界；
- `strategy_metrics.csv`：买入持有及各消融策略的收益、回撤、夏普、费用和相对买入持有收益差；
- `cost_sensitivity.csv`：固定完整策略在单边费率 0、0.05%、0.10% 下的表现；
- `experiment.json`：评估区间、信号来源和固定实验参数。

零收益基线预测下一收盘价等于当前收盘价。Ridge 使用与 TCN 相同的 25 个特征、次日收盘收益标签、1,260 个成熟训练样本、20 日重训节奏和训练窗标准化；`alpha=1.0` 是预先固定的对照参数，不是在正式期搜索得到的最优值。

## 策略消融定义

| 名称 | 仓位规则 |
|---|---|
| `buy_hold` | 始终目标满仓，期初买入、期末清算 |
| `ma20` | 收盘高于 MA20 时满仓，否则空仓 |
| `tcn_only` | 只使用 TCN 的带缓冲持仓判断 |
| `utility_only` | 只使用交易效用模型的二值判断 |
| `dual_consensus` | 只有两模型都持有时才满仓，其余情况空仓 |
| `dual_ma20` | 双模型一致时采用共同意见，不一致时仅在高于 MA20 的情况下半仓 |
| `full` | 仓库原策略，即 `dual_ma20` 加市场宽度补仓 |

这些是不可事后拼接的完整逐日仓位序列，每个方案都重新经过账户模拟和独立账本复核，而不是从最终净值中手工减去某项收益。

## 先做历史验证，再看正式期

```bash
python evaluate.py --start 2024-01-02 --end 2025-10-09 --recompute --out validation_output
```

该命令只使用截至 2025-10-09 的行情，重新滚动训练并输出同一组对照表。模型、阈值和规则只能依据这种正式期之前的历史验证进行选择，冻结后再做正式期最终评价。不能根据 `evaluation_output/` 中正式期收益最高的方案回头替换策略，否则仍然属于测试集调参。

原仓库已经查看过正式期的多种配置，因此新增实验工具不会把已有结果追溯变成独立盲测；报告仍需保留这一限制。

## 自动测试

```bash
python -m unittest discover -s tests -v
```

测试覆盖特征因果性、Ridge 未来数据独立性、训练标签边界、T+1、现金和持仓约束、账务复核、消融仓位规则以及费用敏感性。
