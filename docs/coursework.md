# 中文作业要求：题目一

[下载完整中文作业原件](2026_Coursework_Chinese.docx)。原件包含两个选题、评分与提交说明；本仓库实现题目一「利用所提供数据实现指数增强」。

## 原件要求

- 使用课程提供的创业板日线预处理数据、查阅资料并挖掘因子。
- 自建训练集和机器学习模型，编写程序，并评价价格预测效果。
- 根据预测寻找买卖时机，实现指数增强、争取超额收益，同时尽可能降低最大回撤。
- 可视化最终投资结果，结合实际数据评价策略和模型。
- 报告写明算法、模型、训练过程、特征、数据处理和使用该方法的优点。

初始资金 **100,000 元**；考核区间 **2025-10-10 至 2026-10-23**。满分 100：源代码 60（基本要求 25、投资效果 10、回撤 10、效果评估 10、附加功能 5），最终报告 40。提交物是**含数据的代码包和报告**；报告以 5 页为宜，最多可扩展到 7 页。邮箱、邮件标题、抄送与截止时间以中文原件为准。

## 课程沟通后采用的口径

- 原文“2025年10月10日的数据用来训练模型”经确认指**初始训练只用该日期之前已得到的特征和标签**。测试开始后，可用当时已公布的数据滚动重训。例如某日收盘后，才可把该日已经揭晓的答案用于下一次预测。
- 题目一允许直接按**指数点位**模拟成交，允许使用辅助数据。只做多，无杠杆；当天新买的份额不能当天卖。策略须出现连续空仓。
- 本项目另设买卖单边 0.05% 综合费用、次日开盘成交和按收盘资产计算回撤。这些是项目的模拟假设，不是原件规定的费率或真实 ETF 报价。
